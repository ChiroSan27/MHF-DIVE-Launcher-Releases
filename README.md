# MHF-DIVE Launcher — Releases

Monster Hunter Frontier DIVE のランチャー配布用リポジトリです。
インストーラと、ランチャーの自動更新が読む `latest.json` だけを置いています。

## 必要なもの

- Windows（64bit / 32bit どちらでも動きます）
- **空き容量 6 GB 以上**（ゲーム本体 5.2 GB ＋ 作業用）
- そこそこの回線（初回にゲーム本体をダウンロードします）

## 導入

`MHF-DIVE_*_setup.exe` をダウンロードして実行してください。

インストール先は **どこでも構いません。空のフォルダで大丈夫です。**
ゲーム本体を持っていない状態から始められます。

すでにクライアントを持っている場合は、その `dat` フォルダのある場所を指定すると、
持っているファイルはそのまま使われ、足りない分と古い分だけがダウンロードされます。

### 初回起動

ログインすると、ゲーム本体が自動でダウンロードされます。

- **6,664 ファイル / 約 5.2 GB**
- 回線によっては時間がかかります
- **途中で切れても、次回起動時に続きから再開します。**
  受信済みのファイルはそのまま残り、まだ届いていない分だけを取りに行きます

2 回目以降は、サーバー側で更新のあったファイルだけが落ちてきます。
通常は一瞬で終わります。

## 自動更新

一度入れたあとは、ランチャーが起動時に自分の更新を確認します。
新しい版があればダイアログが出るので、そのまま更新できます。

更新パッケージは minisign 署名で検証されます。署名が一致しないものは
インストールされません。

## ゲームファイルの更新について

`dat` 以下などのゲームファイルは、このリポジトリではなくサーバー側のパッチ機構で
配られます。ランチャーでログインすると自動的に照合され、サーバー側と違うファイルは
差し替えられます（元のファイルは `.diveb` を付けて残ります）。

`mhf.ini`（解像度・音量・ゲームパッド設定）や `keyconfig.cfg` は**この対象外**です。
あなたの設定が勝手に書き換わることはありません。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| ダウンロードが途中で止まる | ランチャーを再起動してください。落とし終えた分はそのまま使われ、残りだけを取りに行きます |
| コントローラーが反応しない | 一度ゲームを終了し、パッドを挿した状態で起動し直してください |
| 容量が足りないと言われる | ゲーム本体に約 5.2 GB、作業用に 0.5 GB ほど余裕が必要です |
