# MHF-DIVE Launcher — Releases

Monster Hunter Frontier DIVE のランチャー配布用リポジトリです。
インストーラと、ランチャーの自動更新が読む `latest.json` だけを置いています。

## 導入

`MHF-DIVE_*_setup.exe` をダウンロードして実行し、**インストール先にゲームフォルダ
（`dat` フォルダのある場所）を指定してください。**

一度入れたあとは、ランチャーが起動時に更新を確認します。新しい版があれば
ダイアログが出るので、そのまま更新できます。更新パッケージは minisign 署名で
検証されるため、署名が一致しないものはインストールされません。

## ゲームファイルの更新について

`dat` 以下などのゲームファイルは、このリポジトリではなくサーバー側のパッチ機構で
配られます。ランチャーでログインすると自動的に照合・更新されます。
